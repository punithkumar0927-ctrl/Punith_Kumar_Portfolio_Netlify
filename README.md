## 🌐 Deploy on Netlify

This is a static HTML, CSS, and JavaScript project, so no build command is required for a standard manual deployment.

### Method 1: Drag and Drop Deployment

1. Unzip the project folder if it is compressed.
2. Open [Netlify Drop](https://app.netlify.com/drop).
3. Drag and drop the complete project folder.
4. Netlify will publish your portfolio and provide a live `netlify.app` URL.
5. Open the Netlify dashboard to change the site name or subdomain later.

Example:

```text
[https://punith-kumar-portfolio.netlify.app](https://punith-kumar-portfolio.netlify.app)
```

### Method 2: Deploy from GitHub

1. Push this portfolio project to GitHub.
2. Log in to [Netlify](https://www.netlify.com/).
3. Click **Add new site**.
4. Choose **Import an existing project**.
5. Select **GitHub**.
6. Choose your portfolio repository.
7. Keep the build command empty.
8. Keep the publish directory empty or use `/`.
9. Click **Deploy site**.

When you update your GitHub repository, Netlify can automatically deploy the latest changes.

## ▲ Deploy on Vercel

1. Push the project to GitHub.
2. Open [Vercel](https://vercel.com/).
3. Click **Add New Project**.
4. Import your GitHub portfolio repository.
5. Select the project.
6. Choose **Other** or leave the framework preset as static.
7. Click **Deploy**.
8. Vercel will provide a live URL.
