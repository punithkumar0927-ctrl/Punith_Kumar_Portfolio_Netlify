# Punith Kumar A B — Portfolio

Static HTML/CSS/JavaScript portfolio, ready for Netlify or Vercel.

## Deploy on Netlify
1. Unzip this folder.
2. Open Netlify and choose **Add new site → Deploy manually**.
3. Drag the project folder into the deploy area.
4. The site will receive a `netlify.app` URL. You can later rename the site/subdomain in Netlify.

No build command is required.
